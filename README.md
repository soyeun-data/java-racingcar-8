# java-racingcar-precourse

# 구현할 기능 목록

## 핵심 기능
- [X] 입력된 자동차 이름을 쉼표(,)로 분리
- [X] 자동차에 이름 부여
- [X] 각 자동차 별로 무작위 값(0~9)을 구함
- [X] 무작위 값이 4 이상일 경우 전진

## 입력
- [X] 경주할 자동차 이름 및 안내 메시지("경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)")
- [X] 시도할 횟수("시도할 횟수는 몇 회인가요?")
- 입력 예외
  - [X] 시도할 횟수가 숫자가 아닌 문자열일 경우
  - [X] 자동차 이름이 5글자를 초과할 경우
  - [X] 자동차 이름을 입력하지 않을 경우
  - [X] 자동차 이름이 중복될 경우

## 출력
- [X] 실행 결과 메시지
- [X] 자동차별 이동 상태 표시 (예: pobi : -- woni : ---- jun : ---)
- [X] 최종 우승자 안내 메시지 ("최종 우승자 : pobi, jun")
